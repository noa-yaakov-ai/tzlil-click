# צליל קליק

לוח סאונד אישי וחינמי מבית הכלים של נועה.

מקליטים או בוחרים קובץ, עורכים בעורך הפנימי, ושומרים כלחצן בלוח שלך.

- חדש: מחולל ביטים (סטפ-סקוונסר) עם 12 כלי נגינה מסונתזים בקוד, ביט אקראי, עריכת טון ומהירות, וקימפול ל-WAV או לכפתור.
- שישה-עשר צלילי CC0 של Kenney (שתי חבילות), כלולים בתוך קובץ האתר.
- כפתורים עם לחיצה אמיתית, בחירת אייקון (אימוג׳י של המכשיר) וצבע לכל צליל.
- הקלטה בדפדפן, עד 60 שניות.
- ייבוא אודיו עד 20MB ועד שתי דקות.
- תצוגת גל וגרירה לבחירת קטע, חיתוך מדויק, עוצמה, מהירות, כניסה ויציאה רכות.
- שינוי מהירות משנה גם גובה צליל.
- ייצוא WAV, שינוי שמות ומחיקת כפתורים.
- שמירה ב-IndexedDB באותו דפדפן. גיבוי ושחזור ידניים לקובץ JSON.
- בלי חשבון, בלי שרת, בלי תשלום, בלי שירותי אודיו חיצוניים ובלי כלי מעקב שלנו.
- הקבצים והקול שלך אינם נשלחים לשום מקום.

`index.html` הוא אתר סטטי עצמאי, עם קוד ועיצוב וצלילי הספרייה בפנים. אפשר להגיש אותו דרך GitHub Pages, בלי התקנות ובלי build. יש להריץ דרך HTTPS או localhost להקלטה ושמירה תקינות.
